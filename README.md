# GlassBench

GlassBench is a community-driven website for smart glasses, XR technologies, spatial computing, and wearable intelligence.

The site brings together product comparisons, technical glossary entries, prototype tracking, and feedback flows to help people explore emerging wearable computing devices more clearly.

## Live Site

https://glassbench.vercel.app

## Project Structure

- `index.html` - static page markup
- `index.css` - responsive styling
- `app.js` - catalog data, filtering, navigation, and feedback form logic
- `favicon.svg` - site icon

## Deployment

This repository is intended to be connected to the GlassBench Vercel project. Pushes to `main` can be deployed automatically through Vercel Git integration.
